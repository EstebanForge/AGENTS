# fsm-design

Designs domain logic, multi-step processes, and agent workflows as strict finite state machines. It fits when a lifecycle has three or more states, boolean flags start multiplying, work must survive restarts or human delays, or repeated agent loops need orchestration. States become enums, transitions stay pure, and the flag soup dies.

## Usage

Ask your agent to model a lifecycle or workflow as a state machine. Or load it by name: "fsm-design".
