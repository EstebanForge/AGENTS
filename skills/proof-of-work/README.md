# proof-of-work

Formats and attaches proof that a change works: screenshots, screen recordings, CLI output, test logs. It picks the right capture tool per surface (web, desktop, terminal) and delivers the evidence where the review happens: PR, ticket, or status update. It never fabricates proof and never swaps visual evidence for logs when the UI changed.

## Usage

Ask your agent to attach proof of the fix or feature. Or load it by name: "proof-of-work".
