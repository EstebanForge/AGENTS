# write-good-javascript

Pre-write companion of [review-my-javascript](../review-my-javascript/README.md). Fires before JS code is drafted; the curated rule set prevents the high-frequency flaws at write time. review-my-javascript stays the enforcement pass on the diff.

## Install

```bash
ln -s "$(pwd)" ~/.agents/skills/write-good-javascript
```

## Usage

Ask your agent to write JavaScript. The skill fires from its description; you can also load it by name: "write-good-javascript".
