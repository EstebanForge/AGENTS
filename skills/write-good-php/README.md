# write-good-php

Pre-write companion of [review-my-php](../review-my-php/README.md). Fires before PHP code is drafted; the curated rule set prevents the high-frequency anti-patterns at write time. review-my-php stays the enforcement pass on the diff.

## Install

```bash
ln -s "$(pwd)" ~/.agents/skills/write-good-php
```

## Usage

Ask your agent to write PHP. The skill fires from its description; you can also load it by name: "write-good-php".
