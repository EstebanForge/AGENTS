# issue

Creates and manages standalone GitHub issues with the `gh` CLI. It follows the repo's own issue templates first and falls back to its own body structure when the repo ships none. Titles keep the repo's Conventional Commits style when the repo uses one. Work that belongs to a bigger story goes through `to-tickets`, not here.

## Usage

Ask your agent to open, update, or comment on a GitHub issue. Or load it by name: "issue".
