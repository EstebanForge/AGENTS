# write-good-typescript

Pre-write companion of [review-my-typescript](../review-my-typescript/README.md). Fires before TS/TSX code is drafted; the curated rule set prevents the high-frequency mistakes at write time. review-my-typescript stays the enforcement pass on the diff.

## Install

```bash
ln -s "$(pwd)" ~/.agents/skills/write-good-typescript
```

## Usage

Ask your agent to write TypeScript or React. The skill fires from its description; you can also load it by name: "write-good-typescript".
