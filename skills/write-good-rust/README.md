# write-good-rust

Pre-write companion of [review-my-rust](../review-my-rust/README.md). Fires before Rust code is drafted; the curated rule set prevents the high-frequency anti-patterns at write time. review-my-rust stays the enforcement pass on the diff.

## Install

```bash
ln -s "$(pwd)" ~/.agents/skills/write-good-rust
```

## Usage

Ask your agent to write Rust. The skill fires from its description; you can also load it by name: "write-good-rust".
