# headless-ui-screenshot

Captures screenshots of desktop GUI applications on headless Linux. It spins up Xvfb on a spare display, runs the app inside a throwaway demo home, and takes the shot so you can verify UI work with no display attached. For web pages, use `agent-browser` instead. This one is for real desktop windows.

## Usage

Ask your agent to visually verify a desktop app on a headless machine. Or load it by name: "headless-ui-screenshot".
